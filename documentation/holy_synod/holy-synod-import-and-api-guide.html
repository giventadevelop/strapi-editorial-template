1. Plan overview

End-to-end flow (same pattern as Directory import):

  1. Schema – Collection type Directory – Holy Synod (api::holy-synod-member.holy-synod-member) with tenant relation.
  2. Scrape – Parse HTML clone + Next.js hub/detail pages + local images from C:\project_workspace\mosc-temp.
  3. Import – Run import-holy-synod-from-mosc-temp.js (Strapi stopped) for tenant tenant_demo_002.
  4. Permissions – Bootstrap grants Public find/findOne; Editor role via grant-editor-directory-permissions.js.
  5. Frontend – Next.js (mosc-temp) fetches GET /api/holy-synod-members filtered by tenant, sorted by order.

6. REST API (frontend)

Public role has find and findOne (granted in bootstrap). Always filter by tenant.

List all members (hub page)

GET /api/holy-synod-members?filters[tenant][tenantId][$eq]=tenant_demo_002&sort=order:asc&populate[image]=*

Single member by slug

GET /api/holy-synod-members?filters[tenant][tenantId][$eq]=tenant_demo_002&filters[slug][$eq]=his-grace-dr-thomas-mar-athanasius&populate[image]=*

7. Frontend integration (mosc-temp)

Replace hardcoded synodMembers in src/app/mosc-redesign/(syro)/holy-synod/page.tsx with a server fetch, following the same pattern as getBishopsData.ts for Directory Bishops.

// Example: src/app/mosc-redesign/(syro)/holy-synod/getHolySynodData.ts
import { getStrapiUrl, getStrapiApiBase, getStrapiHeaders, getStrapiTenantId } from '@/lib/strapi';

export async function getHolySynodMembers() {
  const baseUrl = getStrapiUrl();
  const base = getStrapiApiBase();
  const tenantId = getStrapiTenantId();
  if (!baseUrl || !base || !tenantId) return [];

  const params = new URLSearchParams();
  params.set('filters[tenant][tenantId][$eq]', tenantId);
  params.set('sort', 'order:asc');
  params.set('populate[image]', '*');

  const res = await fetch(`${base}/holy-synod-members?${params}`, {
    headers: getStrapiHeaders(),
    cache: 'no-store',
  });
  if (!res.ok) return [];
  const json = await res.json();
  return Array.isArray(json?.data) ? json.data : [];
}

Map image.url with your existing getMediaUrl() helper (see Directory bishops). Detail pages can fetch by slug or receive data from the list.
