News Import – Catholicate News workflow

Import news articles, advertisement slots, and flash news from catholicatenews.in into local Strapi, then sync to Cloud.

Articles: seed:news_catholicatenews

Ads + flash: seed:ads-flash-catholicatenews

Cloud + S3: see news-production-cloud-push-prd.html

Prerequisites

  1. Local clone of catholicatenews.in or use --live scrape.
  2. Strapi with Article, Category, Advertisement Slot, Flash News Item + multi-tenant.
  3. cheerio, dotenv, mime-types installed.

What the scripts do

Script / npmPurpose
export:news_tenant_demoBackup articles/categories for a tenant.
delete:articlesDelete all articles (categories kept).
seed:news_catholicatenewsImport articles from clone or live site.
seed:ads-flash-catholicatenewsScrape homepage ads + flash; upsert per tenant.
fix:article_category_tenantRepair empty category/tenant in Content Manager.
repair:cloud-news-syncCloud: shells + re-push + S3 + tenant re-link.

How to run (local)

Stop Strapi before delete/seed. Restart afterward so the admin UI picks up data.
1 — Export backup
npm run export:news_tenant_demo
2 — Delete articles (optional)
npm run delete:articles
3 — Seed articles (live, 12 months, both tenants)
npm run seed:news_catholicatenews -- --live --months=12 --tenants=tenant_demo_002,mosc_malankara_orthodox_2
4 — Seed ads + flash from live homepage
npm run seed:ads-flash-catholicatenews -- --tenants=tenant_demo_002,mosc_malankara_orthodox_2
Ads/flash dry-run
npm run seed:ads-flash-catholicatenews -- --dry-run

Ads + flash scrape mapping

PositionSource on catholicatenews.in
topHeader .top-add banner (e.g. Malankara_ad-new.png)
between_sectionsFirst mid-page square promo
sidebarRemaining square promos
Flash items.flash-news carousel links (order + dates)
Lifecycles strip tenant on script creates — the ads/flash seed links tenants via DB join tables after create.

Articles from clone (alternate)

Seed from local HTML clone
npm run seed:news_catholicatenews -- "E:\project_workspace\catholicatenews-in-temp"

Category pages

Seed reads main-news, featured-news, press-release, most-read (up to 30 articles per category). With STRAPI_NEWS_FETCH_MISSING=1, missing pages are fetched live.

Push to production Cloud

Use durable S3 images (--skip-api). Full steps and gotchas: News production Cloud push PRD.
Content + dates + S3 + tenant repair (orchestrator after push)
npm run push:tenant-to-cloud -- --tenant-id=mosc_malankara_orthodox_2 --types=articles,flash-news-items,advertisement-slots --force --delay-ms=80
Restore publishedAt
npm run sync:article-published-dates-cloud -- --tenant-id=mosc_malankara_orthodox_2
S3 article covers
npm run push:collection-images-s3-to-cloud -- --collection=articles --tenant-id=mosc_malankara_orthodox_2 --skip-api
S3 ad media
npm run push:collection-images-s3-to-cloud -- --collection=advertisement-slots --tenant-id=mosc_malankara_orthodox_2 --skip-api
Repair (re-link tenants after cover PUT)
npm run repair:cloud-news-sync -- --tenant-id=mosc_malankara_orthodox_2
Gotcha: Linking covers via Document Service PUT can drop the article tenant relation. Always re-run tenant fix / repair:cloud-news-sync after S3.

After import

  1. Content Manager → Article / Advertisement Slot / Flash News Item.
  2. Filter by tenant (tenant_demo_002 or mosc_malankara_orthodox_2).
  3. On Cloud, confirm cover.url / media.url are amazonaws.com URLs.

Bulk publish

Publish draft articles
npm run bulk_publish:articles

Re-running

Article seed can create duplicates if re-run without delete. Ads/flash seed replaces existing slots/items for the given tenants. For a clean article re-import: delete:articles then re-seed.
