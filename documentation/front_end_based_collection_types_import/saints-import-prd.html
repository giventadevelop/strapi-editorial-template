Saints – Import PRD

PRD / runbook for importing Directory – Saints from mosc-temp into Strapi. Pattern matches Holy Synod import guide. Status: Implemented.

Frontend route: /mosc-redesign/saints

Strapi UID: api::saint-entry.saint-entry

Default tenant: tenant_demo_002

Expected row count: ~7 hub entries + orphan detail pages

1. Schema fields

name, slug, excerpt, body, image, order, tenant

2. mosc-temp sources (under MOSC_TEMP_DIR)

  • src/app/mosc-redesign/(syro)/saints/page.tsx (hub)
  • src/app/mosc-redesign/(syro)/saints/<slug>/page.tsx
  • public/images/saints/ (and related paths)

3. Import script

import-saints-from-mosc-temp.js · npm script: import:saints

Stop Strapi before import (script boots embedded Strapi). Images upload to local disk (NODE_ENV=staging during upload).
Import (replace existing slugs for tenant)
npm run import:saints -- --tenant-id=tenant_demo_002 --replace
Dry run preview
set DRY_RUN=1&& npm run import:saints -- --tenant-id=tenant_demo_002
Refresh Editor directory permissions (after new collection type)
npm run grant:editor-directory

4. REST API (frontend)

GET /api/saint-entries?filters[tenant][tenantId][$eq]=tenant_demo_002&sort=order:asc&populate=image

Public role: find / findOne (bootstrap). Filter by tenant on the Next.js server or proxy.

5. Verification

  1. Content Manager → Directory – Saints → rows for tenant tenant_demo_002
  2. Each entry has body HTML and image in Media Library
  3. Frontend /mosc-redesign/saints loads from Strapi instead of static TSX (when wired)
