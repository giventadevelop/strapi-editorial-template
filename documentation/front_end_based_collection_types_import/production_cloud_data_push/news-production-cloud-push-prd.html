2. Prerequisites

  1. Local news seeded (articles + ads + flash). See News import workflow.
  2. .env: STRAPI_CLOUD_URL, STRAPI_CLOUD_API_TOKEN, AWS S3 vars (AWS_ACCESS_KEY_ID, AWS_SECRET_ACCESS_KEY, AWS_REGION, AWS_S3_BUCKET_NAME, S3_UPLOAD_PREFIX).
  3. Stop local Strapi before embedded-Strapi scripts (push:tenant-to-cloud, S3 push).
  4. PowerShell TLS (if needed): $env:NODE_TLS_REJECT_UNAUTHORIZED='0'

3. Clean wipe + re-upload (articles only)

When Cloud has conflicting/stale articles for the production tenant, wipe first then re-push from local. Categories (main-news, most-read, press-release, featured-news) live on the article relation — wiping articles clears those sections for the tenant.

Wipe all Cloud articles for production tenant
node scripts/wipe-cloud-articles-for-tenant.js --tenant-id=mosc_malankara_orthodox_2
Re-push articles only from local
npm run push:tenant-to-cloud -- --tenant-id=mosc_malankara_orthodox_2 --types=articles --force --delay-ms=80

4. Recommended full sync (production)

1 — Content push (articles + flash + ads)
npm run push:tenant-to-cloud -- --tenant-id=mosc_malankara_orthodox_2 --types=articles,flash-news-items,advertisement-slots --force --delay-ms=80

Or run only the repair orchestrator after a failed partial sync — it deletes empty article shells, re-pushes content, S3-links, and re-links tenants (including a second tenant pass after S3).

6. Gotchas

Cover PUT can wipe title/slug/tenant/category. The S3 linker re-sends preserve fields and maps local category slug → Cloud category documentId. Tenant can still drop — re-link via fix-published / repair:cloud-news-sync after S3.

Never send local category documentIds raw (invalid on Cloud → HTTP 400); always map by slug.

Publish resets publishedAt — use sync:article-published-dates-cloud after content push.

Production images must be S3 URLs (…amazonaws.com/…), not /uploads/…. See cloud image migration fix.

Duplicate flash can appear if push runs twice without replace — delete older duplicates on Cloud or re-seed local then force-push carefully.
