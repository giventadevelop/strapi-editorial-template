3. Prerequisites

  1. Phase A complete: npm run import:institutions -- --tenant-id=tenant_demo_002 --replace (local PRD).
  2. .env: STRAPI_CLOUD_URL, STRAPI_CLOUD_API_TOKEN (Full Access).
  3. Local Strapi dev server stopped (embedded Strapi loads local DB).
  4. Cloud schema includes institutions API (HTTP 200 on /api/institutions).
  5. Image files under public/uploads/ from local import (category images from mosc-temp).
Large push: ~219 entries with ~150ms delay between requests — expect several minutes. Use DRY_RUN=1 first to confirm count.
